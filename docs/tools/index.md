# 工程工具与协作

把工程里的工作说清楚：现在能做什么、为什么被阻塞，以及一项工作属于哪个项目、周期和功能模块。

## 已完成的交互笔记

- [Beads：任务依赖与就绪队列](./beads.html)：点击任务节点，领取、完成任务，观察阻塞如何解除；展开 CLI、持久化和协作边界。
- [Plane：项目协作与工作流](./plane.html)：移动工作项，比较 Workspace、Project、Cycle、Module 的职责，理解团队看板与进度口径。

- [Matt Pocock Skills：AI 编程工作流](./matt-pocock-skills.html)：按当前任务选择技能，理解需求澄清、规格、实现与审查，以及每一步的操作边界。

三篇都是完整的 HTML 阅读页，交互与原理在同一页。页面中的数据是教学样例，刷新即重置，不会连接真实账户或修改项目。

## 怎样搭配

Beads 更贴近代码仓库中的 agent 任务和依赖；Plane 更适合团队共享项目、周期、责任与状态。它们可以分别服务执行与协作，但本站没有实现两者的数据同步。状态、负责人和验收条件需要明确谁维护，避免出现两份相互矛盾的事实。
