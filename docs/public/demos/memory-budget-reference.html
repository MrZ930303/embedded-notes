阶段02 · 单元08 · 构建与启动

内存预算速查

预留只算一次，峰值按生命期，栈按最大可达路径。

有限工作负载 · 原创C11 · 本地候选 · 硬件未验证

先圈容量，再求同时需求

包络能放下、arena能容纳、路径边界齐全，是三个需要分别回答的问题。

先读条件，再用公式

本页压缩单元08的完整推导。任务是采集终端的RAM预算；单上下文、有限声明工作负载、真实且不重叠的C对象。布局与生命周期条件不能从公式中删去。text/rodata常驻Flash；data可同时有Flash初值LMA及RAM运行VMA；BSS占RAM零填充。map只证明选定链接的放置，不证明动态峰值、DMA可达或最坏调用路径。

包络=data+BSS+heap预留+stack预留+guard；各区不重叠，对齐/填充另有归属。另比heap live peak≤heap reservation、stack bounded demand≤stack reservation，不能重复加live，也不能自动跨arena借空闲。

FITS包括等于；EXCEEDS表示新数字超容量。INVALID/OVERFLOW/UNKNOWN保持旧数值报告。heap只有FITS提交state+report，其EXCEEDS也保持旧值。NULL检查不能验证伪造/悬空指针、虚假跨度或别名；heap仅允许init/step建立有效表示。

路径边界与实际证据

max-of-paths先找同时活跃帧；siblings互斥则不相加。声明repetitions乘整路径，IRQ每层完整成本×最大嵌套；都先检查乘法和加法。未给递归次数、未知目标、缺少IRQ边界→UNKNOWN，绝不是安全0。C最多8路径，每路径16帧；无自动调用图分析。

AAPCS32 2025Q1 §6.2.1.1/.2：SP始终4字节对齐，public interface8字节。PM0214 Rev10 §2.3.7 pp.42–44：基本8-word硬件异常帧32字节，padding/FP扩展依配置与状态，handler软件帧及嵌套另算；图12浮点保存扩展18字=72。PSP被打断保存与Handler MSP成本要分别记账。64只是本章aggregate IRQ假定。

GCC13.1.0/x86_64，O0/no-inline/no-tail-call/fstack-usage真实host报告leaf48、middle96、root112，均static，不能替代toy80/64/32。GCC10.3/13.1：static固定帧；dynamic,bounded含动态调整上界；dynamic未bounded只给有界部分。逐函数报告缺完整调用/库/IRQ覆盖，水位只说明已执行条件，map只说明放置。可选ARM交叉对象使用GCC10.3.1/Cortex-M4/Thumb/soft-float及相同O0/no-inline/no-tail-call/fstack-usage，报告leaf40/middle64/root80 static；未链接、未执行。默认沙箱先拒绝启动，限定批准执行上下文后经同一router成功；不是工具损坏诊断。本章没有目标运行、水位、硬件或物理打印证明。

受检运算与复用

下载 memory_budget.h · 下载 memory_budget.c · 下载 stack_probe.c · 下载 README.txt

头文件、实现、probe与说明均为本项目原创，无虚构第三方版权/许可。size_t非负；addition先right≤SIZE_MAX−left，multiplication先value≤SIZE_MAX/numerator。memory_scale_ceil检查分母非零及选定中间乘积，再商+非零余数；可约分比值也可能因中间乘积返回OVERFLOW。

memory_envelope；memory_scale_ceil；memory_stack；memory_heap_init；memory_heap_step完整合同见主章。heap最多8槽、payload>0、alignment非零2的幂；span=round_up(payload+overhead,alignment)，元数据在fictional arena外。模块独立编译不定义MEMORY_BUDGET_TEST，测试定义该宏；probe运行只定义STACK_PROBE_TEST。严格C11、NDEBUG运行检查、I/O失败非零；完整复现参数在README.txt。

首选读AAPCS32 2025Q1 §6.2.1.1/.2区分4/8条件，再核对GCC13.1 §3.19三种qualifier。原章列出已读ST PM0214、GNU ld2.36与Arm AN316 V1.3的版本、范围和证据局限。

遮住答案，保留所有前提

RAM1024含data128/BSS256/heap256/stack256/guard128；heap128 arena中A/B/C/D各32，释放A/C；两条互斥路径80+64+32与80+48，aggregate IRQ64，stack256。分别给出包络、连续48分配和栈结论。

展开独立核对

包络1024，FITS/余0；64free但largest32，48拒绝；max176+64=240，余16。若路径未知则UNKNOWN，不用240继续宣称安全。

隔天更改生命线和路径再算。一次看懂不等于长期掌握；把不清楚的“分账/碎片/UNKNOWN”交给助手追问。
