原创小课 01 · 电路与 C

按下按钮，
为什么读到 0？

只完成一件事：沿着线路解释原始电平，再把有抖动的输入变成一次可靠的“按下”事件。

不绑定开发板或固定引脚通用 GPIO 输入原理人工交互模型 · 未做硬件验证
今天的成果
动作 → 电压 → 逻辑值 → 事件

这四步分清了，就能解释“按下为 0”，也能知道为什么一次动作可能被程序数成三次。

先修：会分辨电源与共地。目标属于学习地图第 01 阶段。

先看电路预测再操作观察抖动解释与验收打印速查
01 /

按下是动作，0 和 1 是电路的结果

手指按下是动作；引脚电压是物理量；程序读到的 0/1 是输入电路判定后的逻辑值。“按下”并不天然等于 1。逻辑 1 的有效电压范围由具体芯片的数据手册规定，不能把它理解成固定的 1 伏。

松开，有上拉

电阻把输入连向允许的 I/O 电源。按钮断开时，引脚被拉向高电平，原始值预期为 1。

按下，可靠接地

按钮把输入连接到 GND；引脚被拉低，原始值预期为 0。程序可把这个 0 解释成按下。

松开，移除上拉

没有其他驱动时，输入可能悬空，原始值无法保证。悬空不代表必然随机翻转。

本课的交互模型与独立练习不依赖指定开发板，讲解“上拉电阻 + 按钮接地”的低电平有效原理。STM32/GD32 等芯片资料仅作实现案例；接入硬件后，内部上拉与外部电阻如何选择，仍须核对实际板级设计和型号要求。输入模式、电气门限与允许电压参考 ST AN4899。

03 /

一次动作，为什么出现三个下降沿？

机械触点可能短暂反复通断，一次按下形成多个电气边沿，这叫触点抖动。上拉解决悬空问题，不能保证消除抖动。见 TI：Debounce a Switch。

先看本课人为构造的数据：初始原始值为 1；在 2、3、4、5、6 ms 依次变为 0、1、0、1、0，然后保持 0 到 20 ms。它有 3 个原始下降沿。若每个下降沿都加一次，一次动作就会被多计。

每 1 ms 采样；候选值连续不变满 5 ms 才更新稳定值。任何原始值改变都重新计时。

人工教学样例，非硬件波形。竖线为当前采样时刻，曲线仅显示已回放的部分；可以逐步看候选值何时开始计时。

默认答案：11 ms，1 次按下。最后一次变为 0 在 6 ms，连续到 11 ms 才满 5 ms。保持 0 不再计数。5 ms 是教学参数；过短可能把抖动当事件，过长会增加延迟并忽略持续时间不足的短按。真实参数需要测量。

04 /

把答案变成能解释的规则

原始值、稳定值与事件，分别是什么？

原始值是一次 GPIO 采样结果；稳定值是过滤器已经接受的状态；事件是稳定值从松开转成按下时的一次通知。本课上拉电路中，稳定值 1→0 产生按下事件；之后持续为 0 不再通知。下拉电路的有效电平要相应改成 1。

电路电阻按钮理想模型的原始值
上拉，按钮接地接入松开1
上拉，按钮接地接入或移除按下并可靠接地0
上拉，按钮接地移除松开，无其他驱动无法保证
下拉，按钮接允许电源接入松开 / 按下0 / 1
下拉，按钮接允许电源移除松开，无其他驱动无法保证
最小例子：连续稳定满 5 ms 才接受

每 1 ms 采样一次。原始值一变，就把它记作新的候选值，并从当前时刻重新计时；候选值连续保持满阈值，才替换稳定值。下面是算法示意，时间来自单调计时，未包含具体芯片驱动、计时器回绕与并发处理。

初始：candidate = stable = 1，since = 0
每次采样 raw，当前时刻 now：
  如果 raw != candidate：
    candidate = raw
    since = now
  如果 candidate != stable 且 now - since >= threshold：
    stable = candidate
    如果 stable == 0：发出一次按下事件

人工示例阈值 5 ms：候选 0 在 2、4 ms 开始后又被打断；6 ms 再开始，11 ms 才被接受。原始下降沿是 2、4、6 ms，共 3 个；稳定下降沿只有 11 ms 的 1 个。

拓展示例：24/25/26 ms 依次变为 1/0/1，34/35/36 ms 依次变为 0/1/0。阈值 5 ms 时，31 ms 接受释放，41 ms 确认第二次按下，总计 2 次；阈值 12 ms 时，释放候选保持不足阈值，第二次按下不会成为新的事件。这演示了延迟与遗漏短状态的取舍。

三个误区与一个故障练习
  • “按钮按下就是 1”：先沿线路确定电平，再定义业务上的按下。
  • “装了上拉就不用消抖”：上拉提供默认电平，触点仍可能反复通断。
  • “悬空一定会随机跳”：悬空只表示无法保证有效值；恰好读到某个值不证明设计可靠。

故障练习：一次按下被计了三次。先核对计数是否直接绑定原始下降沿；再用本页人工数据重现，改为稳定值变化触发事件。上板时检查真实原始波形、采样周期和过滤阈值，不能只凭“看起来好了”确认根因。

如何验收与上板验证

离线验收：解释有上拉松开、按下接地、无上拉松开的三个状态；数出 3 个原始下降沿；说明默认 11 ms 确认一次并持续不重复；加入释放与第二次按下确认 2 次，改变阈值解释延迟。

上板前查实际板卡原理图、完整芯片型号、GPIO 输入门限和允许电压，再确定引脚与上下拉。不要把未知 5V 信号接入 GPIO。本文是通用输入教学，型号与版本要以实际芯片数据手册、参考手册和所用库版本为准。

测量松开与按下的电压；用逻辑分析仪或示波器观察短暂抖动，万用表不能证明短暂抖动不存在。记录采样周期、过滤参数、原始波形、稳定状态与事件计数，并加入释放、短按、第二次按下的测试。此页尚未完成这些硬件实测。

合上解释，再试三个问题
  1. 拿掉上拉，按钮松开且没有别的驱动，为什么不能保证原始值？
  2. 把电路改成下拉、按钮接允许的 I/O 电源：松开与按下各读什么？业务上的按下事件应识别哪一个稳定边沿？
  3. 同一人工输入将阈值改成 10 ms，第一次何时确认？阈值更大要付出什么代价？
核对推理

1. 输入没有确定的高或低驱动，读数不受设计保证。2. 松开 0、按下 1；稳定值 0→1 作为按下事件。3. 最后一次变为 0 在 6 ms，满 10 ms 是 16 ms；响应更晚，短状态可能被忽略。

稍后再不看答案解释一次，或换一个电路推理。哪里说不清，可以继续向助手追问，并指出你卡在“电路、电平、采样还是事件”的哪一步。
