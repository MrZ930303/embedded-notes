调用、事实与政策三层

RECOVERY_OK说明本次合法转移；snapshot category为IDLE/PENDING/READY/FAILED/QUARANTINED。BUSY、INVALID_ARGUMENT、BAD_STATE、TIME_REJECTED、TOKEN_EXHAUSTED、LOCKED等保持型拒绝不覆盖命名状态/输出。first/lastFailure保存cause、serviced phase、actual ADC status/phase、token、attempt、job/attempt年龄与uncertainty；cleanup/reason不覆盖。仅resultPresent读取新result，hasCommitted/committed仅历史。

3 / 20 / 5 / 100 / 20与相等过期

最多3次总attempt（含初次）；每次20ms；匹配cleanup确认起等待5ms；接纳起100ms总期；cancel请求起20ms，包含于总期。顺序：全部参数/状态/input/time验证 → total≥100 → 当前cancel≥20或attempt≥20 → 重放资格/wait≥5 → 0..1 port action。READY/cleanup/stale均不能抢在期限前。接纳0动作；检测失败、取消接受、清理poll、重试start是不同调用。

资源释放与不可抹除的隔离

cancel accepted→cleanup REQUESTED/resource OWNED。仅匹配cleanup confirmation→CONFIRMED/RELEASED。未确认的total/cancel期限→QUARANTINED/UNCONFIRMED，retain request/token，停止所有自动backend动作；submit/reset LOCKED，status/UART仍可用，不继续poll清理。已释放时total到期为干净FAILED。fresh init是新存储/新域/无旧活事件的前提，不是擦live quarantine入口。外部恢复另立合同；取消不撤销副作用。

重放资格必须同时满足

已匹配清理 + wait≥5 + attempt<3 + total<100 + token可用 + 声明的replay-safe原因。READ/ASSIGN仅ATTEMPT_TIMEOUT/NACK/OVERRUN/LOST_REPLY；ARLO/PERMANENT停止。READ须稳定独占、无read-clear/FIFO；ASSIGN须相同已复制值。SAMPLE仅同输入host，原因ATTEMPT_TIMEOUT/ADC_BACKEND/ADC_TIMEOUT。INCREMENT从不自动重放：uncertain→UNSAFE_EFFECT；pre-effect→NOT_REPLAYABLE。失回复已提交counter0→1；独立盲重放再变2。1,000,000上限先拒绝效果。不能推广到硬件读写/线路恢复。

时间域与token域都有限

token正uint32 1..MAX，0表示未发；每start一个，严格递增，MAX后耗尽，不回绕。MAX−1 fixture只发两次，第二次清理后TOKEN_EXHAUSTED；reset不回拨。旧token completion只消费STALE，不提交、不释放当前请求。时间1tick=1ms，真实前向gap<2^31是caller承诺；observed delta≥2^31先拒绝、全命名输出保持；等时合法、未见整圈不可检测。4294967290→4=10ms，→14=20ms先超时；终态年龄冻结。先widen累计，最大活动年龄2147483746可容于uint32。

固定工作、存储和对象契约

1 manager/1 backend/1 actual ADC；值复制，无retained caller payload指针、callbacks、堆、递归、sleep/等待循环。每service0..1 port、内部0..1 ADC lifecycle；3槽report未用清0；optional32行trace，第33行drop newest+typed result/drop计数，manager继续。七个uint32诊断饱和、attempted overflow置sticky flag，MAX seed只是有限测试。所有指针真实/live/typed，输出可写且与其余对象（含嵌套成员）不重叠；fresh init不读旧值，其余调用需已初始化、内部一致、独占单上下文非重入。metadata/null检查不验证forged/dangling/overlap/任意corruption。host .su/sizeof非目标最大栈。

FAKE register/counter/value≤1000000，READ/INCREMENT value0、adc字段0；ADC config fake seeds0，SAMPLE/value0经实际plan+quantize验证。config backend固定。NONE token0/causeNONE；其他事件positive token；FAIL只收相应模式cause，CONTRACT_FAULT内部生成。不可用事件不排队。clean terminal reset保留历史输出、producer committed、fake值、diagnostics、token史。

实际ADC与UART组合核对

实际adc_start + 三次独立adc_poll ACQUIRE/CONVERT/RESULT，从固定12bit/3300000/1650000µV请求得sample2048；report.phase为serviced相、state.phase为下一相。manager先timeout时ADC仍active：下次cancel-request仅接受、再下次active-only adc_cancel一次。producer error已inactive：后续cancel-poll只报保存事实，1 port/0 ADC calls，仍不得同次重试。异常producer return为有效CONTRACT_FAULT隔离，不能伪装保持型BAD_STATE或清理成功。

A5 01 02 03由4次真实uart_receive、一次真实uart_poll解析；commandPresent为新GET_STATUS，period100不变。应用另拷job，responsePresent只授权应用对象，无wire发送。每turn0..4字节/0..5 UART events +0..1 port action；独立component状态/reportValid无atomic rollback承诺。另fresh FAKE fixture在41隔离后42仍可status。浏览器JS活动不能代替此native证据。

资料版本与限制

  1. ST HAL ADC，固定commit b6f0ed…：研究者实际阅读HAL_ADC_PollForConversion与HAL_ADC_Stop；前者依赖HAL_GetTick，HAL_MAX_DELAY跳过期限，判定为elapsed>Timeout并二次查flag。此处≥20是原创策略，非该HAL函数的替身；Stop还涉及injected转换，不能当私有regular-only恢复。
  2. 同固定版本HAL UART：实际有限阅读Receive、wait helper、IRQ错误分支和HAL_UART_AbortReceive_IT；特定接收abort的完成是callback，函数return不是完成。某些内部ORE路径被调用层flatten，故分类与原始detail应分开。不能推广到所有模式/版本；本例没有callback。
  3. 同固定版本HAL I2C：研究者实际读wait/address helper、IsDeviceReady与DMAAbort。特定HAL_ERROR可由AF或timeout引起，需error bits；Trials是readiness probe的局部界限，非任意应用命令重放许可。READY handle不证明物理线路已恢复。
  4. DS8626 Rev12，March2026与历史RM0090 Rev5，September2013：13所选F407VG/LQFP100、假设wired VDDA=VREF+=3.3V、84MHz PCLK2÷4=21MHz的来源条件。当前DS有限文字已读；历史ADC页图由研究者看过，当前RM未获取、当前表格像素未核验，不是最新寄存器配置审计。
  5. AN2834 Rev10，October2024：有限error/settling文字阅读；末转移文字、图与数值冲突保留；典型4pF不是保证上限、源阻抗公式几何未目视。13的floor bins与本章固定2048是原创host算术，不是硬件精度证据。
