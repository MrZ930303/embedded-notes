单元11 · 可打印速查

UART有界命令：条件与恢复

先问本次有什么新证据，再消费输出；帧、自检通过与真实命令身份仍有距离。

4字节 / 5事件 / 1命令

20ms观察服务不活动；失败A5不重试；所有命令按值复制。

先核对对象与观察条件

C11，八位字节及精确uint类型；真实存活全字段初始化state，输出可写并与整个state及彼此不重叠；init可新存储，后续调用独占不可重入。单执行上下文，不是任务/ISR/DMA或并发SPSC；volatile不补同步。固定4槽、payload8、每poll≤4字节/≤5事件/≤1命令，无堆、等待、递归或隐藏重试。硬件未验证。

1tick=1ms；真实正向接受观察间隔<2^31；模差≥2^31返回UART_TIME_REJECTED且队列/残帧/应用/报告/命令输出保持。完整未观察回绕不能探测。初始应用周期1..1000ms。

帧与命令速查

原创协议A5 LEN(1..8) PAYLOAD[LEN] XOR(LEN及载荷)，SOF不参与；最长11字节，无转义/终止符/IDLE或read-call边界。SEEK → LENGTH → PAYLOAD → CHECKSUM；载荷A5只是数据，非法LEN或校验A5消费一次后回SEEK，不重扫。

opcode01须LEN3、小端u16周期1..1000ms；opcode02须LEN1，报告状态且不改周期。校验对不等于命令合法。A5 03 01 64 00 66→100ms；A5 01 02 03→状态；A5 03 01 A5 01 A6→421ms。校验正确的周期0、1001、未知opcode或错专属LEN仍拒绝。

XOR漏检：100ms载荷01 64 00改成01 65 01，仍校验66却变357ms；重排也保持XOR。语义检查排不了所有错误/伪帧，不提供认证、可靠交付或任意噪声下最终同步。

20ms：先到期，再排空

timeout为parser/service观察的不活动期限，不是线缆到达间隔或硬件IDLE。SOF接受开始age，后续预期字节接受归0，SEEK噪声不计。每poll先更新观察，即使空队列也检查age≥20清残帧，再按新SEEK消费当前字节一次。19未到，20等号到期；4294967290→13为19，14累计20。

字节FIFO无时间戳，同次poll共享now。t0解析前缀A5 03 01 64，即使后缀00 66在t1线上到达，到t20才排空仍先超时、后缀当噪声；不能据此断言物理间隔。超时后当前A5可新起帧，FIFO新状态帧可同次产生TIMEOUT+四字节事件共5项。

丢失、拒绝与新输出

FIFO_FULL先由原fifo_push保持四槽与元数据，上层UART_LOSS明确丢弃队列/残帧并丢失败字节（即使A5），保留应用周期；后续新完整帧再恢复，不隐式重试。BAD_STATE是初始化元数据拒绝，不是内存修复。ORE是另一硬件丢失来源，不能精确数丢失字节。

uart_poll的report.commandPresent才授权读新命令；partial/reject/timeout/loss均不改调用者旧命令。已接受结果不能被本次更晚噪声覆盖。命令按值复制；status复制当前周期、不改应用。四计数到UINT32_MAX后饱和，再增标saturated，不默默回绕。

公开接口与完整下载

uart_init(UartState*,uint16_t period,uint32_t now)；uart_receive(UartState*,uint16_t byte,UartIngress*)；uart_poll(UartState*,uint32_t now,UartReport*,UartCommand*)。字节先验0..255；真实对象/不重叠合同见头文件。状态UART_OK、UART_LOSS、UART_INVALID_ARGUMENT、UART_BAD_STATE、UART_TIME_REJECTED；只有LOSS是明确恢复变更，其余拒绝保持命名状态/输出。

折叠回忆：离开实验再解释

seed周期100ms、phase已等状态帧校验，FIFO=03 00 A5 00。先预测本次命令和最终phase，再展开。

核对完整理由

03完成状态命令，复制GET_STATUS100；00噪声、A5新起帧、最后00坏LEN回SEEK，但commandPresent仍真且不能覆盖新命令。预算4；旧帧首字节完成后只剩3，少于最短新帧4，故本次至多1命令。超时场景另可有1个预先事件，总容量5。
