先核对选定对象与四层含义

固定LIS3DH，假设CS高/SA0低用于I2C；未核验板接线。address7=18，写地址字节30，读地址字节31，寄存器SUB=0F，身份期望DATA=33。通用7位数值30合法，本夹具仅判目标不匹配；绝不自动unshift。所钉HAL三个函数另要求先左移，是API特定约定。

SPI采用4线、8位MSB-first，单读命令80|0F=8F。由传感器高空闲/下降发送/上升采样与历史MCU定义推导CPOL1/CPHA1=mode3，只限本例，不替代速率/CS/电气条件核验。

按phase、cause与所有权诊断

目标地址/SUB NACK：仍OWNED→ERROR_STOP，下一poll有限逻辑STOP→FAILED/RELEASED，保留ADDRESS_NACK/DATA_NACK与原failurePhase。若先到20ms，policyCause=TIMEOUT，原cause/phase保留，UNKNOWN且无STOP。ARLO：FAILED/LOST，无STOP；新显式I2C请求仍先WAIT_FREE。ERROR/STUCK/timeout：UNKNOWN，拒绝新start，不可init/reset清掉未决资源。

busy可能正常占用/Sr/可选拉伸/卡线/本地状态，不足以授权九脉冲、reset或电源恢复。必须先查实际线状态、其他controller、所有权及板级权限。逻辑RELEASED不证明物理线路恢复；本接口无retry/cancel/physical recovery。

20ms总期限与旧结果合同

start100→poll119可PENDING；poll120等号先超时，不接受同刻READY。每poll最多一阶段，WAIT/期限/终态零动作。时间依赖真实前进观察和调度，1tick=1ms，true gap<2^31由调用者承诺；观测delta≥2^31拒绝且全状态/报告保持。跨零4294967290→4是10，等tick不增年龄，整圈漏观察不能检测。

I2C ticks0..8九阶段，tick6只有候选，tick8STOP才newResult；SPI ticks0..3四阶段，COMMAND丢7E，数据33到DESELECT才提交。PENDING、准入拒绝、无效时间和所有失败保留旧已提交值。resultPresent可能指旧结果，只有newResult授权消费本轮新值；返回非33可READY但identityMatches=false。

公共接口、常量资源与下载

bus_init(BusState*)只用于真正fresh storage；bus_start(state,request,now)复制protocol/address7/reg；bus_poll(state,now,event,report)一事件/一阶段，没有回调或忙等。BusCallStatus=OK/INVALID_ARGUMENT/BAD_STATE/BUS_BUSY/TIME_REJECTED，报告另有IDLE/PENDING/READY/FAILED，phase/nextPhase/cause/policyCause/failurePhase/resource。

存储恒定：一请求、一候选、一已提交字节；一输入事件/一输出报告，无队列/历史或会溢出的计数器，elapsed饱和20；UI固定路径≤9行。独占单上下文、不可重入，state与其他实参不重叠，真实存活类型/容量/生命周期由调用者保证。NULL检查不是指针有效性证明。UNKNOWN不可复用，LOST允许显式新请求但不证明物理free。

分别编译bus.c/time.c，独立调用者重复包含头，normal和NDEBUG检查都实际生效。AgentHub所有实际C操作使用mcu-build validate→dry-run→build，失败不跑旧产物；保留profile/tool/header/log/rawstatus/fresh artifact SHA。主机.su/栈启发式不等于目标最大栈。
