# C 语言与内存

从对象放在哪里、活多久开始，把「代码里的变量」与「芯片上的内存」对应起来。

## 已发布笔记

### [MCU 堆栈原理与监测](./heap-stack.md)

覆盖堆与栈的区别、指针与动态内存、Cortex-M 栈方向、泄漏与碎片，以及 Keil / FreeRTOS 监测。包含 C 代码示例、工程检查清单和交互实验。

适用范围：STM32 / GD32 等 Cortex-M 工程。8051 等其他内核需要单独核对。

## 建议阅读顺序

1. 先看 [MCU 内存学习路线](../guide/memory-roadmap.md)，知道每一步要验证什么。
2. 阅读完整堆栈笔记，在自己的小工程里检查链接布局和栈预算。
3. 保存压力测试结果，再回头检查技术限定和未知调用链。
